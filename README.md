# Overlay Drawer

Preview em HTML de um overlay drawer (painel lateral com fundo escurecido).

## Rodando localmente

Abra `index.html` no navegador, ou sirva a pasta com um servidor estático:

```bash
python3 -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Estrutura

- `index.html` — página de preview
- `assets/css/style.css` — estilos do drawer e overlay
- `assets/js/drawer.js` — lógica de abrir/fechar
- `assets/icons/close.svg` — ícone de fechar
